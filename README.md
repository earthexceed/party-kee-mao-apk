# ปาร์ตี้ขี้เมา — ไฟล์ติดตั้ง Android

รีโปนี้มีไว้เก็บ **ไฟล์ติดตั้ง (.apk) ของแอปปาร์ตี้ขี้เมา** อย่างเดียว ไม่มีซอร์สโค้ด

- โหลดไฟล์ล่าสุดได้ที่หน้า [Releases](../../releases/latest)
- เล่นบนเบราว์เซอร์โดยไม่ต้องติดตั้ง: **https://party.codex-wiki.com**
- ข้อมูลแอป/ติดต่อ: https://codex-wiki.com/party-kee-mao/

ตอนติดตั้ง Android จะถามว่าอนุญาตให้ติดตั้งจากแหล่งนี้ไหม — กดอนุญาตได้เลย
(ไฟล์เซ็นด้วยกุญแจของผู้พัฒนาเอง ไม่ได้ผ่าน Play Store) · iPhone/iPad ติดตั้งแบบนี้ไม่ได้ ใช้เวอร์ชันเว็บแทน
